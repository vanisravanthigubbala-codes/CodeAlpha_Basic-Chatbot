# 🤖 Basic Chatbot - Python

Welcome to the Basic Chatbot project! This is a simple, interactive, text-based automated chatbot built using Python. 
This project was developed as part of my *Python Programming Internship at CodeAlpha*.

## 📝 About the Project
This chatbot is designed to engage in basic conversations with users via the command line. It can process user inputs, respond to common greetings, provide the current date and time, and politely exit when asked. It demonstrates the use of basic natural language processing logic and Python's datetime module.

## ✨ Features
* Interactive Command Line Interface (CLI) for chatting.
* Responds to greetings (e.g., 'hi', 'hello').
* Can provide the current time and date when asked.
* Graceful exit functionality using keywords like 'bye' or 'quit'.
* Simple and easily customizable code structure.

## 🚀 How to Run the Code
1. Make sure you have Python installed on your system.
2. Download the Python file (e.g., chatbot.py) from this repository.
3. Open your terminal or command prompt.
4. Run the file using the command: python chatbot.py (Note: Replace 'chatbot.py' with your exact file name if it's different)
